# PRO Ecosystem 7.0 BY

База: PRO Ecosystem 6.1, все 10 модулей сохранены без переписывания их существующих расчётов.

## Новое
- Общий Workspace: выбор объекта во всех модулях, создание, сохранение снимков параметров и результатов в IndexedDB, список связанных расчётов.
- Полная локальная резервная копия: IndexedDB Workspace + localStorage, восстановление с подтверждением.
- Диагностика поддержки хранилища, service worker и HTTPS.
- Material Hub: актуальный счётчик позиций с нормами и фасовкой, без фиктивного заполнения.
- Tile Master 3.0: отдельный геометрический расчёт объёма швов и массы по вводимой паспортной плотности. Существующий раскрой и смета сохранены.
- Электрик PRO 5.0: дополнительный контроль расчетного тока по мощности, фазности и cos φ, предупреждение о превышении номинала автомата. Исходный конструктор щита сохранён.
- PWA-кеш обновлён, нет новых внешних зависимостей.

## Ограничения
- Сохранение в Workspace выполняет снимок параметров и отображаемых результатов, но обратная загрузка в калькулятор ещё не реализована.
- Проверка электрики не заменяет нормативный проект, проверку КЗ и селективности.
- Геометрический расчёт затирки не учитывает потери и требует паспортной плотности.
- Неизвестные нормы расхода в Material Hub остаются неизвестными.
- Локальное резервное копирование включает только доступные этому origin данные, не файлы PDF и не данные других браузеров.

Для PWA запускайте через HTTPS (GitHub Pages) или localhost. Распакуйте содержимое ZIP в корень репозитория.


## PRO 7.1 — Workspace
- В окне «PRO 7.0 · Объект» сохранённые расчёты имеют кнопки «Открыть» и «Удалить».
- «Открыть» восстанавливает значения полей; если расчёт принадлежит другому приложению, сначала открывается соответствующий модуль, затем применяются значения.
- Восстановление касается полей с HTML id, а не произвольного внутреннего состояния приложений; некоторые модули могут потребовать повторного запуска расчёта.
- Резервное копирование и прежние функции сохранены.

## Исправление 7.2
- Исправлена загрузка 235 PDF-позиций в общий реестр: ранее использовалось устаревшее имя глобального каталога.
- Калькулятор показывает все материалы, а не только материалы с автоматически распознанной нормой.
- Для неизвестных норм расчёт не выполняется, пока пользователь не введёт проверенное значение.
- Существующие пользовательские записи в localStorage сохраняются.
- Обновлён ключ кеша service worker.


## PRO 7.3 — Анимации
Добавлены плавное появление карточек, янтарная подсветка при наведении, отклик кнопок и анимация нажатия во всех 10 приложениях и хабе. Эффекты отключаются при системной настройке «Уменьшение движения». Без CDN и внешних библиотек. Расчётные функции не менялись.

## PRO 7.4 — Анимированные результаты
- Плавное изменение отображаемых чисел в блоках результатов, включая кг, л, м², шт., BYN и проценты.
- Подсветка изменившихся числовых показателей без изменения вычислительных формул.
- Эффекты отключаются по prefers-reduced-motion.
- Не добавляли фиктивный процент готовности сметы: он потребовал бы настоящих данных о её полноте.
- Все 10 приложений, Workspace и офлайн-кеш сохранены.


## 7.5 — Elegant Motion
- Мягкое появление карточек, тонкая подсветка и плавные состояния кнопок.
- Индикатор прокрутки и кнопка отключения анимаций (сохраняется локально).
- Учитывается prefers-reduced-motion; на мобильных устройствах отключены тяжёлые эффекты.
- Новые файлы в precache PWA; расчётные модули не изменены.


## PRO 7.6 — Design System
- Единая система визуальных токенов, отступов, типографики и скруглений для всех 10 приложений и главного хаба.
- Обновлены карточки приложений, KPI, таблицы, формы, панели и верхний экран.
- Без внешних шрифтов, библиотек и сетевых запросов; все изменения только в CSS и HTML главной страницы.
- Скрипты расчётов, IndexedDB и Material Hub не изменены.
- Поддержка prefers-reduced-motion сохранена.
- Для GitHub Pages загрузите содержимое архива в корень репозитория.


## 7.7 Premium UI
Три темы: Amber Glass, Graphite, Midnight Blue. Настройки оформления доступны во всех 10 приложениях и на главной. Переключение темы не изменяет расчёты. Анимации можно отключить; учитывается prefers-reduced-motion. Все файлы локальны и включены в кеш PWA.

Проверки: наличие ресурсов, JavaScript syntax, ZIP CRC. Полное интерактивное тестирование браузера не выполнено.


## 7.8 — аудит интерфейса
- Убран дублирующий плавающий переключатель анимаций: настройки объединены в одном меню «Оформление».

- CSS подключён к главной странице и 10 приложениям, включён в кеш PWA. Формулы и хранилище данных не изменялись.
