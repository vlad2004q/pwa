# PRO Ecosystem 7.0 BY

База: PRO Ecosystem 6.1, все 10 модулей сохранены без переписывания их существующих расчётов.

## Новое
- Общий Workspace: выбор объекта во всех модулях, создание, сохранение снимков параметров и результатов в IndexedDB, список связанных расчётов.
- Полная локальная резервная копия: IndexedDB Workspace + localStorage, восстановление с подтверждением.
- Диагностика поддержки хранилища, service worker и HTTPS.
- Material Hub: актуальный счётчик позиций с нормами и фасовкой, без фиктивного заполнения.
- Tile Master 3.0: отдельный геометрический расчёт объёма швов и массы по вводимой паспортной плотности. Существующий раскрой и смета сохранены.
- Электрик PRO 5.0: дополнительный контроль расчетного тока по мощности, фазности и cos φ, предупреждение о превышении номинала автомата. Исходный конструктор щита сохранён.
- PWA-кеш обновлён, нет новых внешних зависимостей.

## Ограничения
- Сохранение в Workspace выполняет снимок параметров и отображаемых результатов, но обратная загрузка в калькулятор ещё не реализована.
- Проверка электрики не заменяет нормативный проект, проверку КЗ и селективности.
- Геометрический расчёт затирки не учитывает потери и требует паспортной плотности.
- Неизвестные нормы расхода в Material Hub остаются неизвестными.
- Локальное резервное копирование включает только доступные этому origin данные, не файлы PDF и не данные других браузеров.

Для PWA запускайте через HTTPS (GitHub Pages) или localhost. Распакуйте содержимое ZIP в корень репозитория.
