# PRO Ecosystem 8.2 · Cash BYN

Обновление исходного архива 8.1, без удаления существующих приложений.

## Новое
- Касса BYN: 15 номиналов, точный подсчёт в копейках, расхождения, история localStorage, CSV/JSON, печать.
- Estimate PRO: единая смета, редактирование позиций, материалы/работы/доставка/запас/скидки/расходы, объединение, CSV/JSON и печать. Данные хранятся в `pro-estimate-82-items`.
- Floor Master: дополнительный редактор многоугольников, несколько участков, исключаемая площадь, стяжка, плитка, утеплитель, гидроизоляция, плинтус и передача в смету.
- Garage и Concrete: добавлены формы передачи проверенных вручную количеств в смету, существующие калькуляторы сохранены.
- PWA: новый ключ кэша, precache новых ресурсов, регистрация кассы в реестре.

## Ограничения
- Передача из Concrete и Garage требует подтверждения/ввода количества пользователем; автоматическое считывание ведомости не реализовано.
- Редактор пола предназначен для простых несамопересекающихся многоугольников; исключения задаются суммарной площадью, а не отдельными контурами.
- Инженерные параметры гаража и прочность бетона требуют проверки специалистом.
- Печать в PDF производится средствами браузера.
- Исходные старые данные localStorage не удаляются, но прежний формат Estimate автоматически не импортируется.

Для GitHub Pages публикуйте содержимое ZIP в корне сайта/репозитория.


## 8.3 — единый визуальный стиль и кредитный калькулятор
- Общая CSS-тема подключена ко всем HTML-приложениям, сохраняя существующие компоненты и расчёты.
- В Belgee Finance кнопки внутри калькулятора запускают анимацию поверх всего экрана (без блокировки нажатий); учитывается настройка уменьшения движения.
- Обновлён precache сервис-воркера и исправлен резервный ответ навигации при офлайн-режиме.
- Полноценное браузерное и визуальное тестирование на устройствах требуется перед публикацией.


## 8.4 — единая система интерфейса и данных

- Общий адаптивный визуальный слой и панель инструментов для главного экрана и всех 18 приложений.
- Экспорт всех локальных данных в резервную JSON-копию и подтверждаемое восстановление без очистки остальных ключей. Копии содержат пользовательские данные — храните их безопасно.
- Печать / PDF через системный диалог браузера, навигация в хаб, единая доступная клавиатурная подсветка и поддержка reduced motion.
- Контроль минимальных значений числовых полей на изменении.
- Обновлён PWA precache. Старые ключи localStorage не изменены.

Ограничения: единый слой не заменяет индивидуальные формы каждого калькулятора; инженерные расчёты остаются предварительными. Не выполнялись полноценные ручные браузерные испытания на устройствах.


## 8.5 — усиление интерфейса и Estimate PRO
- Общая дизайн-система с унифицированными состояниями фокуса, мобильными размерами элементов, контрастом таблиц и режимом печати на всех страницах.
- Estimate PRO: поиск позиций и импорт JSON с проверкой схемы и подтверждением. Перед импортом рекомендуется экспортировать резервную копию через общую панель.
- Кэш PWA обновлён до 8.5; добавленные файлы включены в precache.
- Ограничения: импорт обновляет данные при перезагрузке страницы, отмена импорта не автоматизирована; инженерные расчёты и остальные функциональные ограничения версии 8.4 остаются. Полное браузерное тестирование не выполнялось.


## 8.6 — этап 1: надёжная интеграция и единый интерфейс
- Сохранены все приложения и исходные ключи localStorage / IndexedDB.
- Единая компактная навигация, доступный фокус и режим уменьшенного движения на всех экранах.
- Исправлен статический счётчик приложений на главном экране: число берётся из реестра.
- Estimate PRO: независимые версии сметы с названием проекта, датой, подтверждением восстановления, удалением и экспортом JSON. Исходная смета не меняет формат хранения.
- Добавлены новые ресурсы в precache, версия кэша 8.6.

Это первый этап 8.6, а не завершённая переработка всех расчётных модулей. Полное браузерное и офлайн-тестирование на целевых устройствах остаётся обязательным перед выпуском.

## Касса PRO: мультивалютный пересчёт
Подсчёт номиналов BYN, RUB, USD, EUR, PLN, UAH, GBP и CHF; автоматический итог, ручные курсы, сохранение истории, экспорт CSV/JSON. Курсы не загружаются из сети. Данные хранятся локально в браузере.
