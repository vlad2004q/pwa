# PRO Ecosystem 5.4 — Material Hub BY (расширяемая база)

Содержит 10 прежних приложений, сохранённые из 5.3, и расширение Material Hub BY.

## Новое
- Массовый импорт CSV (разделитель ; или ,; кавычки и переносы строк поддерживаются).
- Объединение каталога по ID с существующими позициями, без удаления других позиций.
- Скачиваемый CSV-шаблон для каталога белорусских производителей.
- Передача выбранной карточки из Material Hub в Tile Master через локальное хранилище сайта. **На этом этапе связь информационная, без автоматического изменения расхода в Tile Master.**
- Обновлён офлайн-кэш PWA.

## Важные ограничения
Это НЕ полный каталог всех брендов Беларуси. В стартовой базе по-прежнему только три демонстрационные карточки. Для фактического наполнения нужны официальные машиночитаемые каталоги или проверенные выгрузки поставщиков. Цены BYN, артикулы и нормы расхода не выдумываются. Вводимые CSV-позиции помечаются как непроверенные. Для переноса между устройствами экспортируйте JSON.

Разместите содержимое ZIP в корне GitHub Pages. На `file://` сервис-воркер не работает.


## 5.5 PDF catalog import
Embedded offline index of products from Ceresit 2017, Taifun, Litokol 2026 catalog TOCs. Product series only; not all SKUs, colors, packs or prices. Fields without verified values are blank. Local user edits preserved by ID.


## v5.6: технические данные PDF
Автоматически извлечены доступные нормы расхода и фасовки для однозначно определяемых карточек; добавлен расчёт по толщине слоя. Технические поля помечены как требующие проверки, цены BYN не выдумываются. Некоторые страницы содержат несколько товаров, поэтому их значения намеренно не подставляются автоматически.
