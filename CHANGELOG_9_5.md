# PRO Ecosystem 9.5 — стабилизация

- Резервная копия теперь охватывает все ключи localStorage текущего origin, включая старые приложения без префикса `pro-`. Ранее они не попадали в архив.
- В резервную копию по-прежнему включается PROWorkspace при доступности API.
- Уточнено предупреждение при недоступности НБРБ с датой последнего успешного обновления.
- Добавлен скрипт QA `python3 qa/check.py` для проверки локальных ссылок и синтаксиса JS.
- Обновлён кеш service worker.

Ограничения: автоматические браузерные end-to-end тесты не проводились; восстановление резервной копии заменяет совпадающие ключи, поэтому до импорта сохраните текущую копию.
