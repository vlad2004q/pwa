PRO ECOSYSTEM — ПУБЛИКАЦИЯ С ПК
===================================

Сайт: https://vlad2004q.github.io/pwa/
Репозиторий: https://github.com/vlad2004q/pwa

РЕКОМЕНДУЕМЫЙ СПОСОБ: GitHub Desktop
1. Установите GitHub Desktop и войдите в свой аккаунт.
2. File > Clone repository > vlad2004q/pwa.
3. В GitHub Desktop выберите Branch > New branch, назовите backup-before-update и нажмите Publish branch.
4. Вернитесь на main (Current Branch > main).
5. Распакуйте этот ZIP в отдельную папку.
6. Скопируйте ФАЙЛЫ И ПАПКИ ИЗНУТРИ архива в локальную папку pwa с заменой совпадающих файлов.
   В корне pwa должен находиться index.html, а не дополнительная вложенная папка.
7. В GitHub Desktop проверьте список изменений. Не удаляйте неизвестные файлы.
8. Введите Summary: Update PRO Ecosystem 9.0; нажмите Commit to main и Push origin.
9. Откройте https://vlad2004q.github.io/pwa/ через 1-5 минут.
10. Если старая версия осталась в PWA-кэше, закройте приложение и обновите страницу; при необходимости очистите данные сайта.

ВАЖНО: Сборка 9.0 — интеграционная, не все функции дорожной карты завершены.
Данные localStorage/IndexedDB хранятся в браузере, а не в репозитории.
Перед очисткой данных сайта экспортируйте резервную копию из приложения.
Не загружайте ZIP как один файл для GitHub Pages: сайт должен состоять из распакованных файлов.
